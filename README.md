# morphology

Spatial proportion systems for layout: derive a type scale, spacing scale, and
column widths from one decision.

## What it is

A skills-only bag — no tools, no server, no store. One skill,
**`layout-ratios`**, which applies the 8dp grid, the golden ratio, Fibonacci
spacing, and Material Design principles to HTML layouts.

The point is that the scales are *derived* rather than picked: choose a base and
the type ramp, spacing steps, and column widths follow from it, so a layout
stays proportionate instead of accumulating one-off values.

Reach for it when generating an article, dashboard, or any page whose spacing
should look deliberate.
